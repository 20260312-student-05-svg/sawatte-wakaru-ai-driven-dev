# 成果物テンプレート（チーム：Hiro）

# 1. システムの目的
- システム名：Hiro
- 解決したい課題：受付時間外に予約できない／予約状況の確認に時間がかかる／予約変更・キャンセルの連絡漏れ／二重予約の発生／受付担当者の台帳確認の手作業負担
- このシステムが必要な理由：患者がオンラインで予約・確認・キャンセルでき、管理者が予約状況を一覧で把握できるようにするため
- 今回の対象範囲：最小限の予約管理（予約登録・確認・キャンセル、管理者による予約一覧確認）＋患者の簡易認証（新規：氏名＋電話番号の紐づけ／2回目以降：個人番号）

# 2. 想定ユーザー
| ユーザー | 立場 | 主な目的 | 主な困りごと |
|------|------|------|------|
| 患者 | システムの利用者 | 受診の予約（予約の確認・キャンセルもしたい） | 受付時間内に電話しないと予約できない／予約の変更・キャンセルがしづらい |
| 受付担当者（管理者） | 予約を管理する側 | 予約状況を正確に管理し、受付業務をスムーズにしたい | 台帳確認の手作業負担が大きい／二重予約や変更・キャンセルの連絡漏れが起きることがある |

# 3. 利用シーン
- 例：患者が空き時間を見て予約する
- 例：予約済みの内容を確認する
- 例：管理者が当日の予約一覧を確認する

# 4. 必要な機能
| 機能名 | 誰が使うか | 何ができるか | 優先度 | 理由 |
|------|------|------|------|------|
| 新規予約 | 患者 | 診療科（またはメニュー）と日時を選んで予約できる | 高 | 受付時間外でも予約できるようにするため |
| 新規ユーザー認証（氏名＋電話番号の紐づけ） | 患者 | 初回利用時に氏名と電話番号を登録（紐づけ）し、ユーザーを特定できるようにする | 高 | 予約確認やキャンセルを「本人の予約」に紐づけるため |
| 個人番号による予約枠の確保 | 患者 | 2回目以降は個人番号だけで予約枠を確保できる | 高 | 入力の手間を減らし、繰り返し利用しやすくするため |
| 予約確認 | 患者 | 自分の「今後の予約」を確認できる | 高 | 電話や台帳確認の手間を減らすため |
| 予約キャンセル | 患者 | 予約を取り消せる | 高 | キャンセル連絡漏れを減らすため |
| 予約状況一覧閲覧 | 管理者 | 当日/期間の予約状況を一覧で確認できる | 高 | 台帳確認の手作業負担を減らすため |
| 二重予約防止 | 患者・管理者 | 同じ時間枠への重複予約を防ぐ | 高 | 重複予約による混乱を防ぐため |
| 入力チェック/エラー表示 | 患者・管理者 | 未入力や不正な日時などを分かりやすく伝える | 高 | 入力ミスによる予約トラブルを防ぐため |
| 予約変更 | 患者 | 予約日時（必要なら診療科）を変更できる | 中 | 利便性は上がるが、最小構成は「キャンセル→再予約」で代替できるため |
| 予約履歴参照 | 患者 | 過去の予約を確認できる | 低 | 最初は「今後の予約確認」が優先のため |
| リマインド通知 | 患者 | 受診日前に通知できる | 低 | 便利だが、最小構成の達成には必須ではないため |
| コメント機能（問診表） | 患者 | 予約時に簡単な問診/コメントを入力できる | 低 | 演習の範囲を超えやすいため |
| 予約新規登録（電話等） | 管理者 | 電話などシステム外で受けた予約を登録できる | 要確認 | 電話予約を併用するかで必要性が変わるため |
| 予約変更・キャンセル対応（代行） | 管理者 | 患者の依頼を受けて代行で変更/キャンセルできる | 低 | 最初は患者自身で操作できる前提で進めるため |


# 5. 今回の最小構成
- 最初に必要だと考えた機能：新規予約、新規ユーザー認証（氏名＋電話番号の紐づけ）、個人番号による予約枠の確保、予約確認、予約キャンセル、予約状況一覧閲覧、二重予約防止、入力チェック/エラー表示
- あとで追加したい機能：予約変更、予約履歴参照、リマインド通知、コメント機能（問診表）、予約変更・キャンセル対応（代行）、予約新規登録（電話等）（※電話運用を併用する場合）
- 今回は対象外にする機能：無断キャンセルペナルティ機能

# 7. 学び・気づき
- AIに任せてよかった点：一般的な機能を組み込んだたたき台を出させることによって、議論が進んだ
- 人が決める必要があった点：たたき台に抜け漏れがないのかを確認すること。ユーザーの困りごとを解決するためのアイデア出し
- 要件を整理して見えてきたこと：AIが出力してきたものを人間が精査して、人間がだしたアイデアをAIに精査させることが必要だと感じた
